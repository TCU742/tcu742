# Sitio web del TCU-742

Sitio estático: no necesita servidor ni instalación. Abre `index.html` en el navegador para verlo en tu computadora.

## Archivos
- `index.html`: página de inicio
- `equipos.html`, `talleres.html`, `planes-reguladores.html`, `contenido.html`: páginas internas
- `css/`: estilos compartidos (`sitio.css` y `paginas.css`)
- `img/`: logo del TCU y fotografías

## Cómo actualizarlo
- Textos: abre el archivo `.html` con cualquier editor de texto (Bloc de notas, VS Code) y cambia el texto entre las etiquetas.
- Fotos: reemplaza el archivo dentro de `img/` conservando el mismo nombre, o súbelo con otro nombre y cambia el nombre en el `.html`.
- Colores: están al inicio de `css/sitio.css`, en el bloque `:root`.
